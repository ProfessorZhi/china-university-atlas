# V5 → V5.1 仓库迁移记录

迁移日期：2026-09-08。V5.1 的重点是把原先依赖一台 Windows 电脑临时目录的项目，变成公开仓库中可下载、可审查、可重建的项目。本轮不宣称新增了全国校区覆盖。

## 迁移与完整性

通过用户授权的文件工具复制 Windows 的构建代码、HTML 模板、校区人工增补、名称别名和档案匹配表。对大体量的公开来源重新下载，再与 Windows 文件进行 SHA-256 比较；教育部普通高校、成人高校、排名字段与两份原始位置文件共五项完全一致。363 份边界生成的 compact JSON 也与 Windows 文件的 SHA-256 一致。

使用这些输入重建 V5，最终完整大学/校区/区域/覆盖/缺口数据的规范化 JSON SHA-256 为：

```text
22297c19ef6f2c145009f6f44704386e9f8c7efedd8e38bafac166ca18222128
```

该值与 Windows V5 对应值一致。规范化规则：UTF-8、JSON 对象键排序、紧凑分隔符、不改变数组顺序。详情见 `reports/migration-verification.json`。新 HTML 经过源码拆分、固定压缩时间和版本标记更新，因此不与原 HTML 做字节相同的断言。

## 根因修复

跨平台重建时发现旧地址解析从集合中选择同长度城市名，顺序不稳定，可能把“乐山市峨眉山市”误识别为“眉山市”。历史管线已改为优先地址中最早出现的城市名称，再按名称长度和字典序确定顺序。修复后全部数据内容与原 Windows V5 对上。当前正常构建直接读取仓库已确认的结构化快照，不会每次联网重新猜测地址归属。

## 没有迁入的内容

没有上传浏览器用户配置、cookie、GitHub 令牌、SSH 私钥、本机快捷方式、个人绝对路径或其他项目。没有让 Windows 登录 GitHub，也没有把服务器凭证传给 Windows。Windows 原始地图文件未删除、未覆盖。新的提交和发布使用服务器上已有的授权。

第三方完整学校档案的介绍、图片、视频等不属于本项目必需数据；只保留与校名、地点、来源相关的精简结构化快照。旧设备截图和旧浏览器报告不是新版验收依据，新截图和断网测试报告在服务器重新生成。

## 后续更新入口

大学主体修改 `data/universities.jsonl`，校区修改 `data/campuses.jsonl`；区域与覆盖统计分别维护。每条校区修改必须附来源和核验状态，缺失项应更新对应报告。由 `scripts/build.py` 生成 `dist`，通过验证后再提交、发布，不直接修改已生成 HTML 作为唯一源码。
