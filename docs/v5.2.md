# V5.2 · 地点证据分层

V5.2 的目标不是用猜测快速填满地图，而是把“具体校园地点”和“只能确认到县区的证据”拆开。县区候选因此可以增加，但不会凭县区字段生成校区门牌或经纬度。

## 新的数据层

`data/campuses.jsonl` 继续保存校区/办学地点。记录可来自学校官网、政府公开资料、交叉核对资料、第三方院校档案或历史 POI，并保留不同核验等级。

`data/district-associations.jsonl` 只保存县区归属依据。该文件的记录：

- 可以让学校进入对应县区的候选集合；
- 不计入校园/办学地点数量；
- 不允许包含 `address`、`lng`、`lat`；
- 在县区已有具体校园候选时，不用低精度 association 抢占地图“最佳高校”标签；
- 页面明确显示“非精确校区”。

## 本轮高置信地点增补

本轮新增 11 条地点记录，来源保存在 `data/overrides/v5.2-authoritative-additions.json` 和 `reports/v5.2-authoritative-additions.csv`。其中学校官网/招生章程或政府公开信息用于成都美术学院、太原卫生职业学院、南充卫生职业学院、新星职业技术学院、胡杨河职业技术学院、河南能源化工学院等地点核对；忻州现代康养职业学院、辛集应用技术职业学院采用公开资料交叉核对并保持较低核验等级。

所有新增记录均未伪造经纬度。只有地址而没有可靠坐标时，页面显示地点信息但不画校园点。
