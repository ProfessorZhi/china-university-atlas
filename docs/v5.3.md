# V5.3 · 学校主体、地点与城市语义收口

V5.3 的目标不是宣称“所有校区都已精确定位”，而是把学校主体状态、地点证据精度、最低法定行政边界、异地办学 presence 与排名事实分层，使地图在学校层面不再把“资料缺失”误写成“当地没有高校”，也不让异地校区抢占城市本地主榜。

## 学校主体与地点覆盖

教育部 2026 名录中的普通高校仍为 2,952 所。其中 17 所已按停招、并转或其他失活状态单独解析，当前活跃普通高校为 2,935 所。

当前派生报告中：

- 活跃普通高校缺任何地点证据：0
- 活跃普通高校仅有市级地点：0
- 活跃普通高校没有 campus 记录：4
- 仅靠县区/等效法定边界证据的学校：4
- 校区/办学地点记录：6,817
- 已落到最低可用法定行政边界的 campus 记录：6,089
- 仍只到城市层级的 campus 记录：728
- 县区归属证据：35

这 4 所“无 campus 记录但已有县区证据”的学校是：大连商务职业学院、民办安徽旅游职业学院、江西经济管理职业学院、固原农林职业技术学院。它们不是学校位置缺失，而是精确校区/门牌仍待补。

728 条仅到城市层级的 campus 记录全部属于记录级精度债务，不等同于 728 所学校仍缺县区：当前 2,935 所活跃普通高校均已至少有一条最低法定行政边界级证据。V5.3 因此把“学校级地点覆盖”与“每条 campus 记录的精确程度”分开统计。

## 新行政区边界缺口

仍有 2 所学校已确认到现实法定县级位置，但离线边界基线尚未包含对应新设区域：

- 新疆昆仑科技学院：草湖市
- 新星职业技术学院：新星市

这两项计为 `pending-new-region`，属于底图边界缺口，不再回退成旧城市的本地主体高校，也不伪造县区轮廓。

## 精确地址继承规则

V5.3 新增对“同一学校已有已核验精确地址，低精度档案记录地址文本与其完全对应”的单独继承规则。当前有 58 条记录通过该规则获得县区；宽松的地址猜测继承仍为 0。

也就是说，系统只允许可解释、可复现的精确匹配继承，不会因为地址里出现一个区名或相似词就自动补县区。

## 城市主榜与异地办学 presence

城市层现在只允许**本地主体高校**参与“最佳高校”候选。异地校区、分校、研究生院和研究院不再抢占城市主榜，但可以作为附加 presence 显示。

当前已建模 2 个重点城市、7 条异地办学 presence：

- 深圳：本科校区/分校层包含哈尔滨工业大学、中山大学、暨南大学；研究生院/研究院层包含清华大学、北京大学。
- 苏州：本科校区/分校层包含南京大学苏州校区、中国人民大学苏州校区。

开启“包含异地办学”后，城市标签在本地主体高校名后增加 `＋`，悬浮提示分两层展示本科校区/分校与研究生院/研究院；关闭后 `＋` 和异地层一起隐藏，但城市本地主体高校不变。

GitHub 浏览器回归测试确认：深圳主标签为南方科技大学，苏州主标签为苏州大学；异地办学信息只作为附加层显示。

## 标签避让与离线验收

城市/县区标签采用“逐级缩小字体 → 多位置避让 → 只保留地区名 → 必要时隐藏”的顺序，避免为了强行显示学校名而造成严重重叠。

- 派生表生成与 `--check` 一致
- 离线 HTML 可重复构建
- 数据、事实层与发布卫生校验通过
- Chrome 断网运行通过
- HTTP 请求：0
- runtime errors：0
- 深圳/苏州城市层语义回归通过
- 完整 ZIP 可生成

## 事实层状态

V5.3 同时引入版本化 facts schema 与来源策略：

- 排名事实：27 条，覆盖 10 所学校
- 录取事实：0
- 财务事实：0

空的录取与财务事实层是明确的“尚未录入”，不是用推测值补齐。分类榜、学校整体排名、校区质量与录取难度仍保持语义分离。

## 仍未解决的事项

V5.3 把**活跃学校级地点证据缺口降为 0**，但没有宣称校区数据完全无缺口。后续仍应继续：

1. 为 4 所 district-evidence-only 学校补精确 campus/门牌；
2. 逐步把 728 条 profile 级市级 campus 记录提升到最低法定边界；
3. 获取草湖市、新星市可靠的 2026 法定边界并更新离线底图；
4. 扩展异地办学 presence 到更多跨城办学城市；
5. 在有可靠、版本化来源后继续填充录取与财务事实层。
