## 一句话

外壳的技术诚实度很高，但**信息层级是反的**：页面上最响的三种东西（红色实心「覆盖统计」、23px 地图标题、每行重复两遍的「暂无可比最佳高校」）都不是用户此刻要看的东西；V5.8 的 token 重构已经修掉一半（header 压到 78px、图例色块改成真调色板、SVG/PNG 收进弹窗），剩下的核心问题是**地区行三重重复**（同一句话印 3 次、候选数印 2 次，共 121 个单元）、**移动端页面级滚动**（430×932 文档高 1141px，滚下列表时地图完全离开视口），以及**触屏上 tooltip 不可达**（默认勾选的「悬浮显示异地办学」在手机上只有「＋」看不到内容）。

## 逐区域问题

### 1. Header

**截图基线（1440×900）**：header 底边 y=120 → 高 ≈106px（占视口 11.8%）。构成：40px 红色 logo「山」+ 10px/2px 字距英文 eyebrow + 25px h1 + 11px 四段副标题「Standalone Offline Edition · 省 → 市 → 区县 · 单文件离线 · 0 网络请求」+ 240px 搜索框 + 「数据说明」+ 红色实心「覆盖统计」。

**问题**

1. **副标题与地图右上角 badge 说的是同一件事**。副标题的「单文件离线 · 0 网络请求」= `#modeBadge` 的「Standalone Offline · 0 HTTP」。同一屏上两处声明离线，而且其中一处是标题下最显眼的位置。副标题另一半「省 → 市 → 区县」又和面包屑重复（面包屑在同一个首屏里就写着「全国 › 浙江省 › 杭州市」）。
2. **红色被三种语义占用**：logo 底（品牌）、`#packBtn.accent`（主行动）、地图上 34 个校名（`--accent:#a82b21`）。用户学到「红=学校名」之后，「覆盖统计」这个审计入口就是页面上唯一的红色实心按钮。
3. **层级不对**：`#packBtn`（覆盖统计／缺口审计）比 `#dataBtn`（数据与选取规则）更抢眼，但后者才是理解「最佳」含义的前置。
4. eyebrow 10px + 2px 字距在 78–106px 高的标题条里是正确的品牌点缀，不改。

**源码已改**：副标题换成「真实行政区轮廓 · 全国 → 省 → 市 → 区县」；`.logo` 40→34px；`.header h1` 25→19px（`--fs-6`）；`.header` padding `12px 24px 15px` → `12px var(--sp-6) 11px`；搜索 240→230px；`.mapcard` 高度 `100dvh - 136px` → `100dvh - 172px`。桌面 header 实测应 ≈78px。

### 5. 侧栏 · 地区行 `.item`（**本节是重点**）

**现行行 DOM**（active `renderSidebar` = `src/app.js:152`，文件里有两处同名声明，**后者生效**）：

```html
<button class="item">
  <span class="ordinal">03</span>
  <div>
    <div class="rname">河北省 <span class="chip chip-unresolved">暂无可比最佳高校</span></div>
    <div class="runi unresolveduni">暂无可比最佳高校</div>
    <div class="rmeta">暂无可比最佳高校 · 候选 131 所 · 131 所候选</div>
  </div>
  <span class="arrow">›</span>
</button>
```

**未定论行的重复（已确认，并给出精确来源）**

- `.runi` ← `esc(b.rawU||b.u||'高校数据待补')`；`b.rawU` 由 `winnerFields()`（`src/city-layer.js:50`）给出：`u?u.u:(rs.length?'暂无可比最佳高校':'')`。
- `.rmeta` ← `esc(b.meta) + (b.count?' · '+b.count+' 所候选':'')`；`b.meta` 由 `unresolvedMeta()`（`src/city-layer.js:83-87`）给出：
  ```js
  return ['暂无可比最佳高校', `候选 ${rs.length} 所`, names?('并列候选：'+names+more):'', d.detail]
           .filter(Boolean).join(' · ');
  ```
  第 1 项字面就是 `暂无可比最佳高校`，第 2 项是 `` 候选 ${rs.length} 所 ``；`b.count = rs.length`（同一行再追加「· 131 所候选」）。
- **净结果：同一行里「暂无可比最佳高校」出现 3 次（chip + `.runi` + `.rmeta` 前缀），候选数出现 2 次（「候选 131 所」与「131 所候选」）。**
- **截图证据**：`reports/visual/1440x900-nation.png` 第 03 行（裁切复核）逐字为：
  `03 河北省 [暂无可比最佳高校]` / `暂无可比最佳高校` / `暂无可比最佳高校 · 候选 131 所 · 131 所候选`。
- **影响面**：`reports/best-university-coverage.csv` 中 `status='unresolved_incomparable'` 共 **121 个单元**（district 85 / city 35 / province 1 = 河北省）。其中 city 级（如 `1440x900-zhejiang.png` 的 温州市、`1440x900-hangzhou.png` 的 滨江区）是同一形态。

**附带 bug：本该显示的「为什么没有结论」被字段名吃掉**

`unresolvedMeta()` 读的是 `d.candidates` 与 `d.detail`，但 `WinnerCore.decideWinner()` 的返回对象用的是 **`topEntries`** 与 **`decisionDetail`**（`src/winner-core.js:432、465-470、256-258`）。两个字段名不匹配 → 永远 `undefined` → `names` 永远为空、`d.detail` 永远为空。于是审计侧已经算好的那句话（CSV 的 `decision_detail`，例如「领先候选（…）分属不同榜单体系（职业本科 / 普通本科），名次不在同一标尺上，不可直接比较」）**从未进入 UI**，行里只剩下重复。这就是为什么截图里第三行短得可疑——不是被 clamp，是真的没有内容。

**修法（不碰 winner 语义，不碰测试断言）**

- 硬约束：`tests/best-university-parity.mjs` 断言未定论行的 `.runi` **恰好等于** `暂无可比最佳高校`（`sidebar_unresolved_text`），并断言 `.chip` 的 className 含 `chip-unresolved`。所以 `.runi` 与 chip **不能改**；重复只能在 `.rmeta` 侧消除。
- `unresolvedMeta()` 改为只输出差异信息，并改对字段：
  ```js
  function unresolvedMeta(d, rs, fallback){
    if(!rs||!rs.length) return fallback||'暂无候选记录';
    const top=(d.topEntries||[]).map(x=>WinnerCore.unwrap(x).u);
    const names=top.slice(0,3).join('、'), more=top.length>3?' 等':'';
    return [`${rs.length} 所候选`, names?('并列候选：'+names+more):'', shortReason(d.unresolvedReason, d.decisionDetail)]
      .filter(Boolean).join(' · ');
  }
  ```
  `shortReason()` 按 `unresolvedReason` 给短句（完整句进 `title` 与 tooltip）：`*_cross_system`→「候选分属不同榜单，名次不可直接比较」、`*_no_ranking`→「候选均无官方榜单可比名次」、`*_band`→「候选名次落在同一开放区间」、`*_equal_rank`→「候选名次相同」。
- 计数只保留一处：`renderSidebar` 的 `' · '+b.count+' 所候选'` 保留给**所有**行（统一口径），`unresolvedMeta` 里不再重复计数；或反过来（meta 里给计数、行尾不再追加）——二选一。
- 目标行（10px，1 行内）：
  `03 河北省 [暂无可比最佳高校]` / `暂无可比最佳高校` / `并列候选：河北工业职业技术大学、河北医科大学、邢台学院 等 · 候选分属不同榜单，名次不可直接比较 · 131 所候选`
  （若想保持两行以内，把「并列候选」放 `title` 属性，行内只留「候选分属不同榜单，名次不可直接比较 · 131 所候选」。）

**其他行级问题**

1. **序号在暗示排名**。`.ordinal` 来自 `S.geo.filter(f=>f.name)` 的文件顺序（`01 北京市 / 02 天津市 / 03 河北省 …`），不是排名；而同一屏的图例刚说完「不表示排名」。建议删掉 `.ordinal`，或把它换成有价值的信息（该地区候选数）。现状 ≤430 已 `display:none`。
2. **`sideCount` 与行文案自相矛盾**。现行 `renderSidebar`：
   ```js
   $('sideCount').textContent = `${fs.length} 个地区 · ${fs.filter(f=>{const b=best(f);return b.u||b.status==='unresolved_incomparable';}).length} 个有候选高校`;
   ```
   未定论单元被计入「有候选高校」→ 全国显示「34 个地区 · 34 个有候选高校」，而 34 个里有 1 个明确写着「暂无可比最佳高校」（另有 3 个 `reference_only` 港澳台）。建议改为三段式：`34 个地区 · 有冠军 30 · 暂无可比 1 · 参考标签 3`。
3. **未匹配行的双重否定句**。`no_candidate` 行的 `.runi` 是「高校数据待补」、`.rmeta` 是「当前口径未匹配学校；不代表当地没有高校」——两行说同一件事，而这类单元有 **1,645 个**（占 3,246 个单元的一半）。`.runi` 受测试断言约束必须保留，所以删 `.rmeta` 里的重复句，只留计数；把「无候选 ≠ 没有高校」这句话放到列表头部的 `.sidehead p` 或一个折叠说明里说一次。
4. `.item .rmeta` 现在是 `-webkit-line-clamp:2`；这是把上面第 1 条的重复与超长句「藏起来」而不是修掉——修完 `unresolvedMeta` 后建议放开 clamp（或保留 clamp 但保证正常行不会触发）。
5. `sideDesc` 目前是**对实现道歉**：「全部行政区保留在此；地图隐藏部分文字仅为避免遮挡」（县区层是「校区地址与县区归属证据分层展示；同一学校只计一次候选」）。它占着侧栏最显眼的第二行，讲的却是渲染器。建议改成用户向：「点地图或列表进入下一级」/「点卡片展开校区与地址」；把口径说明移进 `.footnote` 的一行链接。

**样式（当前）**：`.tooltip{max-width:min(360px,80vw);padding:11px 13px;font-size:12px;line-height:1.6;background:#1b3a4bf2}`、`.tooltip strong{color:#fff;font-size:13px}`、`.citymain{font-size:15px;font-weight:600;color:#fff}`、`.tipmeta{opacity:.78;font-size:11px}`、`.citytiers em{color:#b9dbe6;font-size:10px;font-weight:600;letter-spacing:.3px}`、`.citytiers span{color:#fff;font-size:11px}`。

**判定**

1. **层级倒置**：区域名（`<strong>` 13px/600 白）比冠军校名（`.citymain` 15px/600 白）**更小**，而且两者同色同重。用户 hover 一个区，最想知道的是「这里是谁」。
2. **`opacity:.78` 的 11px meta**：在 `#1b3a4bf2` 上对比度约 6:1，AA 达标，但「本科 · 2026软科主榜 3 · 名录所在地」把三种口径（层次 / 榜单 / 位置依据）压进一行 11px，密度过高，且「名录所在地」是内部词。
3. **两层异地办学用括号包裹**：`（哈尔滨工业大学、清华大学、北京大学）`。括号在中文里读作补充说明，而这两层是「额外事实」，应该是列表项；`em` 标签是这一层唯一区分「属于哪一类」的线索，10px 与 11px 正文只差 1px，层级几乎不可见。
4. **触屏完全不可达**：`showTip` 只在 `pointermove` 里调用（`app.js:46`），`pointerdown` 只记录 drag，`pointermove` 一旦 `moved>4` 立即 `hideTip()`（`app.js:46`）；tap 的结果是 `enter()` 下钻。所以手机上「悬浮显示异地办学」只能看到地图标签多一个「＋」，**看不到两层内容**——这也是 §7 里那个文案必须改的真实原因。

### 11. 移动端（430×932 / 390×844）

**实测基线（22:13 截图，逐像素扫描）**

## 移动端规则

1. **唯一滚动容器是 `#list`**（M1）。`html,body{height:100dvh;overflow:hidden}` + `body{display:flex;flex-direction:column}` + `.shell{flex:1;min-height:0}`，地图与侧栏按比例分剩余高度，页面永不滚动。
2. **地图份额**：M2 双条件（≥50% 视口高、≥1.25× 侧栏高）。任何对 `.mapcard` / `.side` 高度的改动都要重跑 M2。
3. **头部限额**：≤430px 时 `header.clientHeight <= 0.10 × innerHeight`（≤93px@932 / ≤84px@844）；目标 88px。
4. **触控 44px**（M4）：`.mapcontrols button`、`.controls label`、`.searchwrap input`、`.actions>button`、`.breadcrumb button`、`dialog .close`、`.schoolmore`、`.searchitem`（已 46px）。
5. **文字下限 11px**（M5）：`.legend`、`.item .rmeta`、`.footnote`、`.tipmeta`、`.controls label` 当前分别为 8 / 9 / 9 / 11 / 9px，全部提到 `--fs-2:11px`。
6. **不截断披露**：`.legend` 允许换行；`#modeBadge` 若截断必须截在语义完整处（缩短文案而不是省略号）。
7. **弹窗几何**：`dialog` 的 `left >= -1 && right <= innerWidth + 1`；表格首列 sticky；`.datafacts` 单列。
8. **断点**：`≤430`（小屏手机）、`431–760`（大屏手机 / 竖屏平板）、`761–1050`（小笔电，`.logo{display:none}` 已有）、`>1050`（桌面）。
9. **触屏没有 hover**：任何以「悬浮」命名的可见文案，在 `(hover:none)` 下必须给出非悬浮的替代路径，否则改词。
