审计对象：`reports/visual/` 下 14 张当前构建截图（本审计实读 10 张：`1440x900-nation / zhejiang / hangzhou / shenzhen / beijing / guangdong / xihu`、`430x932-nation / zhejiang`、`390x844-nation`）＋ `reports/visual/v5.8-visual-audit.json`（14 条路线的机器可读几何）＋ `src/index.template.html` / `src/styles.css` / `src/city-layer.css` / `src/app.js`（`drawMap`、`drawInset`、`drawLabels`、`regionColors`）。

机器读数：14 条路线全部 `pass`，`labelOverlapCount = 0`、`clippedLabelCount = 0`、`labelUiCollisionCount = 0`、`runtimeErrors = []`、`httpRequests = []`、`bootMs ≈ 1672`、`domNodes = 560`（全国层）。几何层面没有缺陷，**问题全部是视觉与信息层级问题**。

---

## 一句话结论

**现在**：它是一张"把数据工程调试面板贴在离线 HTML 上"的中国地图——首屏 2 秒内能读到 3 次"离线/0 HTTP"自证、1 个 100% 缩放读数、6 个筛选开关、7 个地图控件（含 2 个文件导出），地图被 5 组 UI 包围、8 色高饱和色块与海水同色系，第二眼看到的是审核术语而不是地名。
**应该变成**：一张以中国地图为唯一主体、低饱和等明度色块做行政底纹、只留"地名 + 校名"两级文字的克制制图作品——离线能力全屏只说一次且放在用户主动展开处，控件只剩视图操作，标题只说地名。

## 当前问题

### A. 首屏读起来像工程 demo（第 1 问）

1. **同一屏三次自称离线。** `1440x900-nation.png`（全国）：顶栏副标题 `Standalone Offline Edition · 省 → 市 → 区县 · 单文件离线 · 0 网络请求`（11px）、地图右上角绿色胶囊 `Standalone Offline · 0 HTTP`、底栏 `单文件离线 · 24 份边界 · 3159 所普通高校 · …`。加上启动卡与"数据说明"弹窗，同一条实现事实在产品里有 5 处出口，首屏同时可见 3 处。视觉后果：第一眼读到的是构建属性，不是地图。

2. **底栏是构建日志。** `1440x900-nation.png` 底部：`24 份边界 · 3159 所普通高校 · 19007 条办学地点` ＋ `边界依源数据快照展示 · 非测绘 / 导航用图`。这是仓库统计与法务免责，两者都不属于地图界面。

3. **调试读数进了图例。** 全部 1440 截图左下角：`100% · 字体随缩放变化`。把"缩放时字体会跟着变"讲给用户，是在解释实现，不是在使用说明。

4. **地图标题块与产品标题几乎同重。** `1440x900-nation.png` / `1440x900-zhejiang.png`：地图标题 `h2` 23px / `font-weight:800`，产品标题 `h1` 25px / `820`。两者只差 2px 与 20 字重，视觉上分不出谁是主体。地图标题块（面包屑＋h2＋说明行）叠在画布左上，约占 300×90px。

5. **每个标题都以 "· 参考" 结尾。** 8 张 1440 截图无一例外：`各省最佳高校 · 参考`、`浙江省 · 各市最佳高校 · 参考`、`杭州市 · 各县区最佳高校 · 参考`、`西湖区 · 高校与校区`。同一句口径声明在每一层重复；"参考"是免责声明，不是标题。

6. **页面在标准笔电上仍然滚动。** `1440x900-nation.png` 右缘可见滚动条滑块（约从顶到 815px），地图卡片底边与状态栏被切掉约 25–30px。布局算式：顶栏 108px ＋ 卡片 `calc(100dvh - 136px)` = 764px ＋ 14px 外边距 ＋ 状态栏 ≈ 925px > 900px。一个地图应用在 1440×900 上不该出现滚动条。

### B. 地图不是主体，chrome 是（第 2 问）

7. **地图被 5 组 chrome 包围。** `1440x900-nation.png`：卡片 1055×762（占视口宽 73%、高 85%），其内部左上角标题块、右上角离线胶囊、右侧 7 按钮玻璃面板（约 50×330px）、左下角图例、右下角 100% 读数；侧栏另占 327px（视口宽 23%）。**静态 chrome 合计遮掉画布约 12%**，且没有一组可收起。

8. **header 过重。** `1440x900-nation.png`：顶栏 108px（视口高 12%），40px 红色圆角方块 logo ＋ 10px/2px 字距的全大写 eyebrow `CHINA · UNIVERSITY ATLAS` ＋ 25px/820 标题 ＋ 11px 副标题 ＋ 搜索 ＋ 2 个按钮（其中"覆盖统计"是饱和红实心）。在"看地图"这件事上，顶栏的视觉重量大于地图标题。

### C. 色板读起来像儿童地图（第 4 问）

9. **8 色里有 3 色与海水同色系。** 色池（`app.js:4`）`#b9d6e6 / #ceddb5 / #f2d49f / #cbbce0 / #edc4ca / #b8dbd3 / #efc9a8 / #c4d3e8`；海水与卡片底同为 `#dceef3`（H193 S49 L91）。其中 `#b9d6e6`（H201）、`#c4d3e8`（H215）、`#b8dbd3`（H166）与海水同一色相带。

10. **极端证据：县区层整张画布就是海水色。** `1440x900-xihu.png`（浙江省 · 杭州市 · 西湖区）：唯一多边形填 `#b9d6e6`，铺满 1055×762 画布，背景是 `#dceef3`。**"这是陆地还是水面"无法判读**；全图信息密度只有 1 个标签 `西湖区 / 浙江大学` 与 7 个 3–4px 圆点。

11. **饱和度差 2.3 倍，相邻省份明艳与灰暗并列。** `#f2d49f` S76% / `#efc9a8` S69%（橙黄）对比 `#b8dbd3` S33% / `#ceddb5` S37%（灰绿）。见 `1440x900-nation.png`（新疆＝橙黄、西藏＝灰绿、青海＝紫，三者相邻）与 `1440x900-guangdong.png`（云浮＝灰紫、惠州＝橙）。等亮度（全部 L 79–85%）但等亮度恰恰让饱和度差异变成唯一的视觉信号 → 读成"彩虹拼图"。

12. **hover 把整块填色换成饱和黄 `#ffe09b`（H41 S100% L80%）。** `styles.css:2` 的 `.region:hover{fill:#ffe09b!important}`（交互见 `1440x900-nation.png`）。一次悬停就让"颜色＝行政身份"的语义被覆盖，同时把已压低的饱和度整体破功。

13. **图例在说谎。** 全部 1440 截图左下角图例只画 **4** 个色块 `#b9d6e6 / #cbdcb5 / #f1cfa5 / #cebfe1`，而地图实际使用 **8** 个填色；且这 4 个 hex 与色池并不一致（图例 `#cbdcb5` vs 色池 `#ceddb5`、`#f1cfa5` vs `#f2d49f`、`#cebfe1` vs `#cbbce0`）。

14. **红字校名在色块上不达 AA。** 校名红 `#c62d28` 对 8 个填色的对比度分别为 **3.10 / 3.51 / 3.57 / 3.63 / 3.63 / 3.71 / 3.84 / 3.86**（最差 `#cbbce0` 3.10），小字需要 4.5。它现在完全靠 2.2–2.8px 白描边撑可读性。地名色 `#274b5a` 对填色 5.27–6.56，达标。

15. **白描边过重，标签像贴纸。** `drawLabels`（`app.js:37`）对 10–11px 文字使用 `stroke:#ffffff;stroke-width:2.2`（带校名时 2.8）。描边宽度≈字高的 1/4，见 `1440x900-nation.png` 的 `哈尔滨工业大学`、`1440x900-guangdong.png` 的 `广东以色列理工学院`。

### D. 控件是调试控件（第 3 问）

16. **7 个按钮混了三种东西。** 全部截图右侧竖排：视图（`＋` `−` `适应` `返回`）× 4 ＋ 布局（`全屏`）＋ **文件导出（`SVG` `PNG`）**。导出是给作者/审阅者的能力，放在"看地图"的一级控件里，直接把产品气质拉回工具脚本。且同一面板里 `＋` 用全角 U+FF0B、`−` 用 U+2212，字号 21px，与 `适应/返回/全屏` 的 11px 并排，字形大小差近 2 倍。

17. **玻璃面板是全图第二重的元素。** `city-layer.css:17`：`.mapcontrols` 有 `backdrop-filter:blur(10px)` ＋ `#ffffffd9` ＋ 12px 圆角 ＋ `0 8px 24px` 阴影。整份 CSS 里**只有这一处用毛玻璃**，于是它独自成为视觉焦点之一，与地图争夺注意力。

### G. 排版与制图细节

23. **折行是硬切字符，中文词被劈开。** `wrap(s,n)`（`app.js:37`）按固定字数切片：`1440x900-hangzhou.png` 桐庐县 → `浙江工商大学杭州商学 / 院`；`1440x900-shenzhen.png` 宝安区 → `广州涉外经济职业技术 / 学院`。

## 修改建议

> 每条标注其修复的问题编号（P#）。所有建议均为本地 CSS/SVG/内联值改动，不引入在线字体、CDN、远程图片、Service Worker，不拆分单文件，不改数据与 winner 语义。

### R1 收掉"离线"的重复自证（修 P1、P2、P3）

- 顶栏副标题：`Standalone Offline Edition · 省 → 市 → 区县 · 单文件离线 · 0 网络请求` → 只留 **`省 → 市 → 区县`**（11px，`--ink-2`）。删掉英文版名与 HTTP 声明。
- 删除地图右上角 `.modebadge` 的常驻显示；把 `Standalone Offline · 0 HTTP` 与"24 份边界 / 3159 所高校 / 19007 条办学地点"整体移入 `#dataDialog`（数据说明）与启动卡，只在侧栏/页脚保留**一处**极简声明：`单文件离线`（10px→11px，`--ink-2`）。
- 删除图例里的 `#zoomInfo`（`100% · 字体随缩放变化`）；缩放百分比只保留在开发者可查的 DOM 属性里。
- 底栏 `statusbar` 合并为一行：左 `单文件离线 · 边界按源数据快照展示`，右 `非测绘 / 导航用图`（11px，`--ink-2`，无边框）。
- 结果：全屏"离线"出现次数 3 → 1。

### R2 标题降级，地图升为主体（修 P4、P5、P8）

- `.maptitles h2`：`23px / 800` → **19px / 700**，`letter-spacing:.4px`；`.maptitles p` 11px 保留但改 `--ink-2`。
- 标题文案去掉口径后缀：`全国` / `浙江省` / `杭州市` / `西湖区`（`updateCrumb()` 里把 `· 各市最佳高校 · 参考` 一段移到 `mapSubtitle`，且**只在首次进入时**显示一次）。
- 口径声明（本科优先 / 参考候选 / 不冒充全国排名）**统一只在 `#dataDialog` 出现**。
- `.header h1`：`25px / 820` → **25px / 700**；`.header` 内边距 `18px 24px 15px` → **`14px 20px 12px`**（顶栏 108px → 约 84px，视口高占比 12% → 9.3%）。
- 地图卡片高度：`calc(100dvh - 136px)` → **`calc(100dvh - 118px)`**，`min-height:600px` → `min-height:560px`；`min-height:640px` 的 `.shell` 删除。目标：1440×900 无滚动条（P6）。

### R3 换成克制的制图色板（修 P9–P13）

**原则**：等明度（L 85–88%）、中低饱和（S 9–35%）、**色相全部避开 160–250**（即不与海水同色系）。色池 8 → 4，正好与图例的 4 个色块一致。

|---|---|---|---|---|---|---|
| `--land-1` 沙 | `#E5DCCB` | 39 | 33% | 85% | 8.47 | 4.74 |
| `--land-2` 苔 | `#DDE2D1` | 78 | 23% | 85% | 8.71 | 4.99 |
| `--land-3` 丁香 | `#E2DAE4` | 288 | 16% | 87% | 8.44 | 4.81 |
| `--land-4` 陶土 | `#EBDAD5` | 14 | 35% | 88% | 8.52 | 4.83 |
| （可选第 5 色）`#D9DFDC` | 150 | 9% | 86% | 8.53 | 4.79 |

- 海水 / 地图底：`#dceef3` → **`#E9F1F3`**（S 49% → 29%，H 192）。陆地与海水在**色相**上彻底分离：陆地 H∈[14,78]∪[150,288]，海水 H=192，任何一块陆地都不再可能被读成水面（修 P9、P10）。
- 页面底：`#eef3f5` ＋ `linear-gradient(180deg,#f4f7f8,#edf2f4)` → **纯 `#F4F7F8`**（去掉渐变）。
- 色池数组（`app.js:4`）改为 4 值；`regionColors()` 的"邻接取不同色"算法（`app.js:29-30`）**保留不动**，只是色池变小。

## 修改后的设计原则

1. **地图是唯一主体。** 叠在画布上的静态 UI 不得超过画布面积的 8%，且任何一组都应以一次点击收起。
2. **一个事实只说一次。** 离线 / 单文件 / 数据口径 / 边界免责，全屏各出现一次，且放在用户主动展开的地方（数据说明、页脚单行）。
3. **标题只说地名。** "最佳高校 · 参考"这类口径句不进标题；标题的职责是回答"我在看哪里"，不是免责。
4. **颜色不承担事实。** 色块只区分行政身份：等明度、低饱和、且不与海水同色系；不表示排名，hover 不换色相，选中用描边而非填充。
5. **一层一个影子，一档一个圆角。** 全产品 2 个阴影、3 个圆角；同层级元素必须逐像素一致。
6. **文字只有两级。** `#16323F` 主线与 `#5A7280` 副线；不存在第三种灰，不存在 10px 字。
7. **默认界面不出现实现词。** HTTP / 边界份数 / 数据条数 / 缩放百分比 / 避让 / 去重 / SVG / PNG，只在"数据说明"或导出面板里出现。
8. **制图完整性优先于方便。** 主图、in图、图例、比例提示共用同一套描边、填色与字号；inset 是地图的一部分，不是一个框。
9. **手机是同一张地图的另一种取景，不是缩小版。** 手机首屏只保留地图、地名、4 个视图控件；其余下沉。
10. **诚实措辞是产品资产。** "暂无可比最佳高校 / 高校数据待补 / 唯一候选"这类表述要保留，只统一它们的视觉重量。
