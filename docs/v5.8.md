## Visual decisions

以下每条都是**实测驱动**，不是口味。对比度用同一段脚本对 `src/app.js:15` 的六色填充计算，取最小值。

### 1. 水是一层材料，不是页面底色

`MAP_STYLE.canvas` `#c7dade` → `#a5bdc6`：对六色填充 **1.12 → 1.52**。旧值下海与陆是同一个明度材料，国家读起来像"亮页面上挖的洞"；新值下海是图，陆是底。`--canvas-edge` → `#8aa6b1`。

**代价（已修）**：`MAP_STYLE.island` 是唯一没有跟着海一起移动的值，而它的全部职责就是"与海分离"——`#7f97a3` 对旧海 2.12、对新海只剩 **1.56**，所有未命名陆地要素静默丢掉三分之一的图底关系。已修为 `#5a7480`（对海 **2.52**），并刻意避开两档边界描边色，使岛不会被误读成边界。

### 2. 边界阶梯要能读成界线

三档由 `.95/.8/.65` × `#6f8b96`/`#7895a5`/`#8ba0aa` 改为 `1.0/0.9/0.8` × `#5f7c88`/`#647f8b`/`#6a8490`，对填充 **2.80/2.45/2.11 → 3.44/3.28/3.06**。三档彼此对填充的离差只有 ±0.01，即"哪一档"只由线宽和上下文决定、不由色相决定；宽度仍保留 `1.0/0.9/0.8` 阶梯，所以黑白打印时层级靠线宽可分。`vector-effect: non-scaling-stroke` 保证缩放时粗细稳定。

### 3. 南海诸岛 inset：从"什么都没有的框"到有标题的面板

三处改动，每一处都由实测推着走：

- **底板**用 `insetWater #8aa6b1` 而非海色。审计主张"inset 是海的一部分搬过来"，实装偏离了：礁盘陆地是 `insetLand #eef3f1`，对深水 **2.29**、对海色只有 **1.75**，回到海色会让"inset 里近乎空白"原样复现。代价是底板与主海只差 1.31，面板完全靠 1px 边框立住，未加渐变/纹理/阴影。
- **标题带**。`#45636f` 在新 inset 水上实测 **2.50**，审计建议的 `#274b5a` 也只有 **3.65**——两者都不过小字号的 4.5 门槛，因为那条建议是按**旧海色**算的，底板一变深就整体失效。实装改为在框顶画一条 `insetLand` 色带、标题用 `#274b5a` 压在上面：**8.36:1**。副产物是标题不再被读成"缩放按钮的说明文字"（普通用户测试的原始表述）——有底色的标题带天然归属于面板。
- **字号** 8–9px → **10px**（全宽度统一）。

### 4. 引线必须真的看得见，否则豁免不算数

标签不与自身色块重叠时会被引线连回，`tests/visual-layout.mjs` 据此豁免 mislabel 判定。但原文 **20/34 的标签带引线**，而引线是 `.6px` + `opacity .5`，混合后对填充 **1.73:1**、对海 **1.46:1** —— 等于 `mislabelCount: 0` 是**豁免出来的**，不是量出来的。

改为 `1px` / `opacity 1` / `#4a6b78` / `non-scaling-stroke`（对填充 **4.44:1**），并新增一条不按视口分档的断言：`leaderIllegibleCount`（宽度 <1px、透明度 <0.9、或对比度 <3 即计一次）。同时发布 `leaderMeasured` 与 `leaderWorstContrast`，使这条断言**不能靠"什么都没测到"而通过**——实测 `leaderMeasured: 127`、`leaderWorstContrast: 4.44`，与手算一致。

### 5. 两个文字层级要有明文，而且要在读者会看的地方

地图印两档文字：L1 行政区名（`#45636f`，对填充 4.98）、L2 最佳高校（`#a82b21`，对填充 5.36）。图例里的键行说明了这件事，但它是整屏最小最轻的一行，且排在色板免责声明之后——读者被引去找它，找到的是免责声明，于是把红色读成"警告"。

改法克制：键行用 `order:-1` 排到最前，连接词从 `--muted` 提到 `--ink-2`。不新增元素、不改宽度。之所以用 CSS `order` 而不是挪 DOM，是因为该行插入在 `#zoomInfo` 之后有明确的布局原因（见 `src/v57-ui.js` 注释），那个原因没有变。

### 6. 移动端：折叠次要筛选，把列表带回第一屏

实测 430×932：header 90 + 地图卡 559 + 标题区 80 + **筛选条 157** = 地区列表从 y=912 开始，`itemsVisibleCount: 1`，即**整个列表几乎全在折线以下**。滑动读者看到的是一个色块地图和一条 20px 的缝，无从知道下面还有列表。

根因是我自己引入的：`styles.css` 里那句注释写"两行约 44px"，实测是**四行 157px** —— 一个从未量过的成本数字，差了 113px。

修法：五个"数据范围"类筛选（异地办学 / 成人高校 / 权威依据 / 大学名称 / 标签自动避让）在手机上折进一个纯 CSS disclosure（`#advFilters` + `label[for]` + `display:contents`），**地图标签字号滑块留在外面**——它作用于读者正在看的那张图。桌面端用 `display:contents` 让 wrapper 不生成盒子，五个 label 仍是 `.controls` 的直接 flex 子项，布局逐像素不变。

实测：折叠 59px / 列表可见 **118px**；展开 157px / 可见 20px（与修前完全一致，可逆）。

### 7. 控件与图例不能再抢同一个角

地图卡左下角同时住着图例，右下角是缩放控件列。实测 **390 和 430 都**存在 `legendVsControls` 重叠 **56×25**；390 上还有 `legendVsInset` 重叠 **58×13**。

两者根因不同：

- 控件列：`.mapcontrols{bottom:28px}` 是按**单行图例**定的，图例加上键行后变成 47px 高，于是控件列压在免责声明上。改为 `bottom:62px`，并删掉 ≤430px 那条 28px 覆盖。
- inset：`drawInset` 里读 `legend.getBoundingClientRect().height` 拿到的是 **25px**（首次绘制发生在 `v57-ui.js` 填充图例**之前**，读到的是占位文本高度），而图例最终是 47px，于是为 53px 的占位只预留了 41px。修法是把预留带改成**量出来的最坏值**而非实时读数：47+6+13 = 66（手机）、47+11+14 = 72（桌面），实时测量仍可把它抬高。

修后三处重叠全部为 `null`。

**代价（已记录）**：inset 上移后其避让框覆盖了更多地图面积，手机端多隐藏 1–2 个标签（390：7→9，430：4→5）。墨压墨是缺陷，藏标签是 §23/§24 明确允许的取舍、且侧栏保留完整信息，所以这个方向是对的——但它确实有成本，不隐藏。

### 8. 产品外壳降噪

- `modeBadge`「单文件离线 · 0 HTTP」→「**离线可用**」。0 HTTP 是构建验收数字，不是读者能据此行动的信息；它留在《数据说明》和页脚给审计者看。
- 图例色块改为由 `palette` 生成，图例不可能与地图不一致。
- 头部 `--accent` 实心按钮删除（全站最响的控件，且在跟红色校名抢注意力），`--accent` 的唯一归属是地图上的最佳高校名。
- 移动端 9px 文字全部提到 `--fs-1`（10px）；图例 8px → 10px 且不再省略号截断（被截掉的正是"不表示排名或层级"这半句，删了它色块就会被读成排名）。

### 9. 不改的东西

`winner-core.js` 判定原则、高校主体数据、campus 数据、ranking facts、Best University winner 语义，本轮**一行未动**。`best-university-parity.mjs` 的 `problemCount: 0` 是这件事的证据，不是它的结论。

## 已知未闭合项

这一轮**没有**修完，逐条写明，不用"基本完成"糊过去。

1. **`wordBreakCount: 5` —— 中文校名会在词中断行。** 实测 `浙江工商大学杭州商学院` → `浙江工商大 / 学杭州商 / 学院`（`大学` 被劈开），同类还有 `杭州科技职业技术学院`、`电子科技大学中山学院`、`上海中侨职业技术大学`。
   **这不是 V5.8 引入的**：V5.7 基线截图里同样是 `桐庐县 浙江工商大学杭州商学 院`。`wrapText` 的旧注释声称"重新平衡后 6+6 而不是 9+3"——这句承诺从未兑现，已改为如实说明。
   **为什么没有修**：行数由排版器能给标签的宽度决定，而这个标签每行只容约 5 字。12 字的校名在 5 字预算下**不存在**干净的三分——词边界只有"浙江工商大学"之后和"杭州商"之后。抬宽度或降字号都会打破重叠保证。改为在测试里**公开计数**（`wordBreakCount`），使这个缺陷不能悄悄变大，也不再假装不存在。
2. **手机端仍有单元拿不到标签**：390 缺 9 个 + 5 个仅地区名；430 缺 5 个 + 4 个仅地区名（34 个省级单元）。§23 明示"可读性优先于全部显示、侧栏保留完整信息"，§24 允许极端情况下隐藏高校名保留地区名。测试用 `labelsMissing` / `silentOnAnswer` 发布名字而不是隐藏计数；`silentOnAnswer` 只在 ≥1440 断言（该宽度下排版器可证成功），更窄处只报告。**这是物理限制，不是已完成项。**
3. **`minLabelFont: 9.6px` 仍低于 UI 最小字号 10px。** `tinyFontLabels` 的阈值是 9，所以 9.6 不被拦。红队建议把下限提到 10.5，1440 下有余量；本轮未做。
4. **地图上没有"你在哪个单元里面"的显式外轮廓。** 制图审计建议的 T1（当前视图外轮廓用父级 ring 重画）本轮未实现，`MAP_STYLE.single` 只用于单一要素视图。这是制图纪律上最明显的一处欠缺。
5. **`insetLand` 对礁盘不生效**：礁盘是亚像素多边形，近白填充活不下来，实际靠 0.6px 描边显影。`insetLand` 目前只活在标题带里。
6. **降级标签在图上没有信号**：1440 全国视图里"河北省"是一个没有校名的裸地区名，33 个邻居都有校名，而唯一的说明在侧栏里。红队建议在图例键里加一句"仅地区名=空间不足"，本轮未做。
7. **`heavyHaloLabels` 断言恒不触发**：断言条件 `stroke > max(2, fs*0.16)`，而代码上限是 `min(2, max(1, fs*0.11))`，两者不可能相交。这是一条死检查，未清理。
8. **`MAP_STYLE.canvas` 在 `src/styles.css` 里手工镜像**，两处一个真值、无测试守护。`insetWater`/`insetLand` 则刻意没有 token。两种策略并存，未统一。
