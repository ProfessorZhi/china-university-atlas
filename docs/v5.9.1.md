# V5.9.1 · 城市 winner 与持续缩放 hotfix

V5.9.1 修两件用户可见的问题：有高校候选的城市不得因为榜单体系不可直接换算而看起来“没有大学”；连续滚轮 / 触控板缩放不得在每个显示帧搬动所有文字并重算玻璃层。

## 所有非空行政单元必须有 winner

V5.9.0 为了避免把不同发布体系的裸名次硬比较，会把跨榜、开放区间或完全无榜单名次的领先候选留成 `unresolved_incomparable`。这在审计语义上保守，但地图上会让“有 8 所 / 16 所高校候选”的城市表现得像没有最佳高校。

V5.9.1 改为：**只要 competition pool 非空，就必须发布一个 winner。** 强证据仍然优先；无法由同榜证据唯一分开的情况转入显式项目政策，不冒充发布方排名：

1. 学校层次与国家重点标签继续先收敛候选池；
2. 公办 / 民办分裂继续执行既有 `public_before_private` 项目规则；
3. 跨榜时按声明的 `GROUP_PRECEDENCE` 选择体系，普通本科主榜在职业本科 / 高职体系之前；
4. 同一体系若只剩开放区间、同名次或完全无排名，再按榜单覆盖层级、区间下界、公办属性和稳定名称顺序作最终 deterministic fallback；
5. 第 3–4 步一律标为 `resolved_policy`，不能标成 `resolved_strong`。

因此 1,598 个有候选行政单元现在全部有 winner：382 个 `resolved_strong`，1,216 个 `resolved_policy`，`unresolved_incomparable = 0`。

典型修复：

- 山东省淄博市：8 所候选 → **山东理工大学**；
- 山东省潍坊市：16 所候选 → **山东第二医科大学**。

两地原本并非缺学校。淄博的县区候选包含山东理工大学、齐鲁医药学院、淄博职业技术大学、山东工业职业学院、淄博师范高等专科学校等；潍坊包含山东第二医科大学、潍坊学院、山东科技职业大学、潍坊科技学院以及多所高职院校。V5.9.0 的空白来自 winner policy，而不是高校名录或大专数据缺失。

## 持续缩放性能

V5.9.0 已做到“wheel 期间不完整重排标签”，但真实持续触控板手势仍会跨很多 animation frame。旧 fast path 每帧仍逐个移动所有可见标签、刷新比例尺，并让地图在多层 `backdrop-filter` 下移动，实际设备仍可能卡顿。

V5.9.1 的 active-gesture path 只做：

- `#shapes` / `#edgeLayer` 两个 SVG group 的 transform；
- 一个小型 zoom percentage 文本更新；
- 重置 idle timer。

手势期间标签层暂时隐藏，不逐 label 写 transform；header / controls / legend 暂停 backdrop blur。停止约 180 ms 后只执行一次完整标签布局，再恢复标签。`inRing()` 的 base-space 查询按 ring + point 缓存，最终地理 guard 也从每个 label 线性扫描 `S.base` 改为一次 Map lookup。

CI 除原来的 48-event burst gate 外，新增持续手势门禁：72 个 wheel event 分散在约 36 个页面时钟 tick 中，必须跨多个 animation frame，同时满足 active gesture 期间 0 次完整 label layout、0 个逐标签 transform、label layer suspended、blur suspended、idle 后恰好一次 layout、leader line 0、HTTP 0、runtime error 0。

高校主体、campus、ranking facts、行政区边界均未因本 hotfix 减少。
