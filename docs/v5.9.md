# V5.9 · Premium Atlas

V5.9 是纯前端产品层升级。高校主体、campus、ranking facts、Best University winner 语义与 `src/winner-core.js` 均不改变。

## 目标

把 V5.8.1 的“地图主导”进一步做成真正的交互式 atlas：地图铺满视口，默认不画引导线，文字只属于自己的行政区；搜索和主要操作悬浮在地图上，完整列表改成按需展开的 Drawer / mobile sheet。

设计参考的是高端消费网站共同的原则——少、稳、留白、层级清楚、动作顺滑——而不是复制任何品牌的视觉资产或组件。

## 零引线与渐进披露

V5.9 默认地图的 `leader line = 0`。标签尝试在行政区内部显示“行政区名 + 最佳高校”；空间不足时先降级为只显示行政区名，再隐藏标签。完整 winner、候选学校与证据始终保留在右侧 Drawer / 移动端 bottom sheet，因此地图不再为了“把所有文字塞上去”牺牲可读性。

标签使用真实文字宽度与语义断行；行政区名为深灰次级信息，最佳高校为深红主信息。最终渲染后还会复核标签中心是否属于自己的行政区，失败时直接隐藏，不跨区拉线补救。

## 丝滑缩放

V5.8 的主要性能问题是每个 wheel / pointer frame 都可能触发完整 `drawLabels()`：文字测量、候选搜索、polygon containment 和 collision packing 会一起运行。

V5.9 将交互分成两条路径：

- **交互中**：只更新地图 transform、已有标签锚点和 campus pins，不做完整标签排版。
- **停止约 150ms 后**：只做一次完整 label layout，再淡入稳定结果。

滚轮输入还会在 `requestAnimationFrame` 内合并。CI 的专用性能门禁一次连续发送 48 个 wheel event，实际结果为：

- `wheelEvents = 48`
- `wheelFrames = 1`
- 交互期间完整 layout 增量 = **0**
- idle 后完整 layout 增量 = **1**
- 标签字号比例 before/after = **1.000**
- runtime error = **0**

因此地图缩放时放大的是地理图形，不是把文字也同步吹大；标签保持近似屏幕空间字号。

## Premium UI

- 地图在桌面与手机都成为视口主体。
- Header 改为轻量半透明悬浮条；不依赖网络字体、图片或 CDN。
- Hover 只显示“行政区 + 最佳高校”的小卡，不再用大黑色信息块遮住地图。
- 完整地区/高校列表默认收起，通过“浏览”打开玻璃质感 Drawer；手机为 bottom sheet。
- 新增动态比例尺，随当前地图层级和缩放改变。
- 地图 controls、legend、搜索框统一为轻量悬浮层。
- `prefers-reduced-motion` 下关闭非必要过渡。

## 验收契约

V5.9 新增 `tests/premium-atlas.mjs`，将以下条件作为 CI 红线：

1. 默认、缩放中、缩放后引导线均为 0。
2. 连续 wheel burst 中完整标签 layout 为 0 次。
3. 停止交互后恰好补 1 次完整 layout。
4. wheel event 必须发生帧合并。
5. 标签字号在缩放前后保持稳定。
6. 动态比例尺存在。
7. Drawer 默认关闭且可显式打开。
8. 0 HTTP request，0 runtime error。
9. `tests/best-university-parity.mjs` 继续 `problemCount = 0`。
10. 单文件 HTML 继续受 5,000,000 bytes 预算约束。

V5.8 的 `visual-layout.mjs` 继续运行并产出截图、碰撞、裁切、颜色与几何报告，但其中“尽量把每个 winner 都印在地图上”和“手机地图占 50–70%”是旧产品策略，V5.9 已明确改为零引线渐进披露与全屏地图，因此该测试作为迁移期证据而不再决定 CI 成败。

## 离线约束

V5.9 仍然是 Standalone Offline Edition：单一 HTML、`file://` 直接打开、运行数据与边界全部内嵌、0 HTTP、无需本地服务器、无需账号、无需 API key，也不内嵌或分发字体文件。
